Architecture trajectory

From a fixed mix demo to a composable audio-agent host.

Ghost now separates signal evidence, context presentation, agent execution, processor adaptation, child hosting, transport, and interface concerns. EQ and compression remain the first useful composition—without becoming the core architecture.

01 / The decision

Dependency direction is the product constraint.

Domain and protocol point inward. Every technology choice—Codex, SQLite, TCP, egui, CLAP, or a future WebView—sits behind a replaceable boundary.

02 / Migration trajectory

Six cuts through the old coupling.

  1. 01

    Protect the signal evidence

    Kept fixture behavior intact while splitting analysis configuration, features, extraction, and decoding.

  2. 02

    Generalize the inputs

    Added Symphonia media decoding and replaced input/post-EQ/output with caller-named, preallocated taps.

  3. 03

    Move mix out of core

    EQ, compression, mix validation, prompt recipe, and mock processing became an outward workflow.

  4. 04

    Make context a compiler

    Components now decide ordering and representation. The response schema travels with the compiled context.

  5. 05

    Turn Codex into infrastructure

    Transport, threads, tools, typed events, and text/JSON turns are independent of the mix workflow.

  6. 06

    Prove the host boundary

    A vendor-neutral graph and fake child cover audio, smoothing, bypass, mapping, state, GUI, and destruction.

03 / The composed system

One loop. Explicit owners.

Agentic audio loop

  1. 1
    Capture

    The graph exposes task-selected taps without hard-coded processor positions.

  2. 2
    Analyze

    Deterministic modules produce reusable signal evidence.

  3. 3
    Compile

    A project/persona/task recipe shapes evidence and the response contract.

  4. 4
    Propose

    The runtime streams events and returns opaque text or structured output.

  5. 5
    Validate · map · ramp

    Workflow policy validates intent; adapters bind it to scanned public parameters.

  6. 6
    Evaluate or stop

    New evidence can continue the loop without placing an agent on the audio thread.
